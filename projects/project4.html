    Micro IoT Car

    Pesrsonal Project

    Designed and built a compact 60×80 mm smart car with a 3D-printed structure, CAD modeling, and ESP32-based IoT control.

    Project Gallery

    Project Overview

    The Micro IoT Car is a compact differential drive robot (60×40 mm) designed to access confined spaces where human reach is limited. It is ideal for inspection, exploration, and small-scale robotic applications in tight environments.

    The robot is fully IoT-controlled for remote operation and is built using 3D printing, making it low-cost and easily reproducible. This project focuses on miniaturization, affordability, and practical usability in real-world scenarios.

    My Role

    • Designed the Micro IoT Car using Fusion 360 as a personal project
    • Developed and built the IoT control circuit for remote operation
    • Programmed the IoT controller for real-time control
    • 3D printed all structural parts of the car
    • Selected and integrated compact electronic components
    • Performed soldering and hardware assembly
