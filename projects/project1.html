    Semi-Humanoid Robot

    Rezilyens LLC

    Designed and developed a semi-humanoid robot by handling complete CAD modeling, circuit design, ROS 2 integration, and system-level programming.

    Project Gallery

    Project Overview

    We are developing a semi-humanoid robot designed to assist individuals with autism through calm, structured interaction, while also performing reception and guidance tasks in real-world environments. Its human-like design and responsive system make it suitable for safe and approachable communication in public and care spaces.

    The robot also functions as a multi-role assistant, handling security monitoring, acting as a watchdog, and receiving updates from team leaders to generate concise summaries. This project integrates robotics, embedded systems, and intelligent software to enhance accessibility, automation, and operational efficiency.

    My Role

    • Led the overall mechanical design of the semi-humanoid robot as the Design Engineer
    • Created detailed engineering drawings for fabrication and assembly
    • Coordinated and fabricated parts through external vendors following design specifications
    • Assembled and built the complete robot system
    • Worked on ROS 2 for autonomous navigation using the Nav2 stack
    • Developed manual control system using a remote interface
    • Integrated and handled electronic components and system wiring
